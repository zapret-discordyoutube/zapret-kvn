# Главная, серверы и локальная GeoIP

Главная использует стандартные карточки qfluentwidgets и прозрачные поверхности
для Mica. Подробные графики и процессы доступны на внутренних страницах.
Нормальный размер окна сохраняется; восстановление выполняется при загрузке
состояния, а не при каждом изменении настроек. Базовый минимум — 860×560,
первый размер — 1000×720 логических пикселей с ограничением по рабочей области.

Серверы показаны через одну Fluent TableView с плоской моделью и строками 28 px. По умолчанию они сгруппированы по ID
подписки; одноимённые подписки не смешиваются. Группировку можно отключить либо
переключить на поле группы, страну или протокол. Столбец имени больше не
растягивается вслед за окном. Меню «Вид» управляет столбцами и группами;
избранное доступно через контекстное меню и меню «Ещё». Поиск скрыт до Ctrl+F.
Мышь, множественное выделение, двойной щелчок, копирование ссылок, контекстное
меню и клавиатурная навигация остаются доступны. Тонкие границы строк и колонок
рисуются только в видимой области, без создания виджета для каждого сервера.

Флаги и состояние активности обновляют только соответствующие ячейки. Пакеты
метрик пересортировывают список только при изменении текущего ключа сортировки.
Обновления метрик свёрнутых групп не отправляют уведомления представлению;
их пересортировка откладывается до раскрытия. Данные и выделение сохраняются.
Сортировка сохраняет постоянные индексы; при изменении состава списка выделение
восстанавливается по ID оставшихся серверов, а свёрнутые группы — по ключам.

## Данные и совместимость

- `Node.is_favorite` и `Node.country_override` сохраняются вместе с профилем.
  Обновление подписки переносит эти поля через существующее сопоставление узлов.
- `country_code` — вычисляемое поле в памяти. Старые сохранённые предположения
  о стране при загрузке игнорируются.
- Настройки вида имеют `nodes_column_layout_version = 2`, поля `nodes_group_by`,
  `nodes_favorites_only`, `nodes_collapsed_groups` и сохраняемые ширины всех
  столбцов. Индивидуальная видимость столбцов сохраняется при миграции.

## Сетевой контракт GeoIP

Ручной выбор страны имеет приоритет. Если в имени есть флаг-эмодзи, используется
его код страны; эмодзи убирается только из отображаемого имени и заменяется PNG.
Оригинальное имя и ссылка сохраняются. Обычные слова и буквенные коды в имени
не используются для угадывания страны.

Для серверов без флага используется локальная DB-IP Country Lite MMDB.
Оно никогда не вызывает DNS, DoH/DoT, HTTP, внешние GeoIP API, тестовые
подключения или запросы внешнего IP. Домены без уже известного IP остаются без
страны. Результаты штатного разрешения endpoint передаются пассивно;
геолокация не инициирует разрешение и не меняет routing/DNS конфигурацию ядра.

Для AWG/WireGuard используются peer endpoint, а не адрес интерфейса или
AllowedIPs. Разные страны у неоднозначных endpoint означают отсутствие
автоматического результата. Ручная страна имеет приоритет. Флаги загружаются
только из настоящих PNG; неизвестный код или недостающий файл не подменяются
полосами либо другой картинкой.

## Сборочная база

`release_windows.py` перед фиксацией исходников нового stable запускает
`prepare_geoip.py --refresh`. Скрипт получает последний доступный ежемесячный
снимок с официальной страницы DB-IP, проверяет MMDB и записывает дату и хеши
в `scripts/geoip-lock.json`. Бинарные данные остаются в `.cache/geoip`.

`build.py` включает закреплённые данные в `assets/geoip` вместе с атрибуцией.
Dev/stable gates проверяют хеш в итоговом payload. Возобновление релиза не
выбирает новую базу; несовпадение хеша или недоступность источника при подготовке
нового stable останавливают соответствующий этап. В приложении нет загрузчика
или кнопки обновления GeoIP.

Источник и лицензия: [DB-IP Country Lite](https://db-ip.com/db/download/ip-to-country-lite),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Запуск и проверки

Splash удалён. `StartupLoader` читает состояние в рабочем потоке и передаёт
ранние параметры темы и геометрии до показа окна. Виджеты и Qt-модели остаются
в GUI-потоке. Неоткрытые страницы получают последние снимки через DeferredPage
и создаются при первом обращении. Версии ядер и пресеты подготавливаются
отдельно; геолокация не задерживает подключение.

Отмена до загрузки состояния не сохраняет пустое состояние поверх реального.
Логи запуска содержат длительность подготовки и готовности управления.
Проверки включают 10 000 узлов, устойчивость выбора и ширин, запрет сетевых
вызовов из GeoIP, отмену загрузки и проверку сборочных хешей. Проверка Mica и
фактического времени запуска Windows EXE выполняется после ручной сборки.

## DNS и первое подключение

Штатные JSON-шаблоны sing-box используют native fallback: DoH через VPN →
прямой DoH с устройства → системный DNS. Внутри каждого DoH-этапа три
резолвера проверяются параллельно с ограниченным временем ожидания. IP адреса
DoH заданы явно, сертификаты проверяются по TLS server_name. NXDOMAIN
считается ответом, а не причиной обходить настроенный resolver.

Переход на резерв отмечается WARN в логе ядра и предупреждением интерфейса.
Для системного DNS отдельно указано, что запросы могут быть видны провайдеру.
Последовательность принадлежит JSON, приложение не внедряет DNS-политику
в пользовательские конфиги. Обновление шаблонов сохраняет изменённые пользователем JSON.

Проверка готовности Amnezia ограничена тремя волнами HTTPS-проб. Быстрый DNS
REFUSED больше не повторяется непрерывно до общего тайм-аута. Отмена подключения
прерывает дальнейшие попытки, а успешная HTTPS-проба ожидает статистику handshake
без запуска новых волн.

Hysteria использует тот же общий SOCKS/HTTPS probe, что и Amnezia. До старта
sing-box DNS готовность транспорта проверяется по IP с исходным TLS SNI и
проверкой сертификата, без зависимости от DNS удалённого узла. Штатный QUIC
режим соответствует Android: ChromeParrot выключен, параметры obfs и TLS pin
из профиля сохраняются. Информационные сообщения официального клиента теперь
попадают в редактируемый журнал и позволяют отличить успешную авторизацию от
провала последующей HTTPS-проверки. Промежуточный сетевой тайм-аут при старте
не выдаётся за итоговую ошибку, пока не закончены остальные пробы; ошибки
сертификата и авторизации обрабатываются сразу.
